# overwatch_randomizer

Один HTML-файл `overwatch-randomizer.html`: рандомайзер героев Overwatch 2.
Открывается офлайн, ничего не отправляет в сеть.

## Правила

- **Всё в одном файле.** Стили, скрипты, шрифты (base64 woff2) и портреты героев
  (base64 webp) вшиты внутрь. Никаких css/js/картинок рядом не создавать.
- **Ростер правится в начале `<script>`**: массив `HEROES`
  (`n` — имя, ключ портрета; `ru` — русское имя; `r` — роль; `u` — ульта или
  `null`; `t` — описание) и карта `PORTRAITS` (ключи совпадают с `n`).
- Портреты — 2D-иконки `File:Icon-<Имя>.png` с фанатской вики
  overwatch.fandom.com, пережимать в WebP ~320px, обрезая прозрачные поля.
  У имён с не-ASCII (Torbjörn, Lúcio) ответ wiki-API декодировать строго UTF-8.
- **Ничего в облако** не выкладывать: шрифты и портреты — фанатские материалы
  по Overwatch, репозиторий личный.
- **Проверка изменений:** открыть файл в браузере, прокрутить пару раз,
  консоль должна быть чистой; персистентность (громкость/роли/история/мешок)
  лежит в localStorage под ключом `owr2` — при смене формата хранения
  поднимать ключ (`owr3`), чтобы не ломать сохранённое.
- Прошлые состояния проекта — в истории git (коммиты до редизайна),
  отдельных файлов-бэкапов не держать.
