# Overwatch Randomizer

Рандомайзер героев Overwatch 2 в **одном HTML-файле**: [overwatch-randomizer.html](overwatch-randomizer.html).
Открыть в браузере — работает офлайн, ничего никуда не отправляется.

## Что умеет

- **Роли-тумблеры** — танки / урон / поддержка, клик по карточке включают-выключает роль; прокрутка идёт только по отмеченным.
- **Два режима**: «Без повторений · мешок» (по умолчанию) — у каждой роли свой мешок, шарик вынимается до конца, потом мешок наполняется снова; и «Классический рандом» — сначала равновероятно роль, затем герой внутри роли.
- **Челленджи-анимация прокрутки** с звуком (WebAudio, синхронные тики) и щедрым финальным салютом.
- **Настоящие шрифты OW** вшиты base64: BigNoodleTooOblique (заголовок, имена героев), Futura No2 D Demi Bold (остальной текст).
- **2D-портреты всех 44 героев** вшиты base64 (взяты с фанатской вики overwatch.fandom.com).
- Громкость с вертикальным слайдером, история прокруток с мини-аватарками и очисткой, счётчик мешка со сбросом.
- Персистентность в localStorage: громкость, режим, роли, история, состояние мешков.

## Как добавить нового героя

В начале `<script>` два места:

1. `HEROES` — строка `{n:"Имя", ru:"Официальное русское имя", r:"tank|dps|supp", u:"Кратко: что делает ульта", t:"Описание"}`.
2. `PORTRAITS` — `"Имя":"data:image/webp;base64,..."` (портрет с вики `File:Icon-Имя.png`, ужать в WebP ~320px).

## Источники

- Портреты и данные героев — фанатская вики [overwatch.fandom.com](https://overwatch.fandom.com).
- Шрифты — фанатский BigNoodleTooOblique и Futura No2 D Demi Bold.
